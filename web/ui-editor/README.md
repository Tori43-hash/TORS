# Конструктор бота TORS

Веб-приложение, в котором собирают бота: добавляют модули из маркета, рисуют экраны на холсте так, как их покажет
Telegram, и получают `bot.json` — файл, по которому `tors build` собирает бинарь, а `tors run` запускает бота.
Проверки и отрисовка экранов — тот же Go-код, что в боте (`theme/`), собранный в WebAssembly.

## Как пользоваться

- **Пустой холст.** Сначала есть только `/start`. «Новый экран» создаёт экран; первый экран сразу открывается по `/start`.
- **Модули.** Маркет с разделами «Официальные», «Проверенные» и «Свои». Модуль приносит свои экраны и нужные ему модули;
  если чего-то не хватает (например, панели для подписок), это видно в панели «Бот». Настройки модуля — форма из его описания.
- **Свои модули.** Соберите бинарь со своим модулем, выполните `tors describe --package ваш/модуль -o tors-module.json`
  и откройте файл в разделе «Свои». Такой модуль помечен как непроверенный.
- **Экраны.** Нажмите на экран или кнопку — справа откроются свойства: текст по языкам с переменными модулей, фото,
  ряды кнопок (кнопки в одном ряду делят ширину поровну, как в Telegram), что делает кнопка, условия, списки, ввод текста.
  Потяните за точку справа от кнопки к другому экрану — появится переход.
- **Проверка.** Внизу слева — ошибки, из-за которых бот не запустится. «Проверить» открывает чат-симулятор.
- **Экспорт.** Показывает, что осталось настроить, переменные окружения и команды запуска; скачивает `bot.json`.
  «Открыть» принимает `bot.json`, `tors-module.json` или файл с экранами; можно перетащить файл в окно.

Проект сохраняется в браузере. ⌘Z / ⇧⌘Z — отменить и повторить. Всё работает локально: конструктор ничего не отправляет.

## Запуск

Нужны Go 1.27+ и Node.js 22+.

```sh
npm ci
npm run dev      # собирает WebAssembly и запускает Vite на http://localhost:5173
```

## Хостинг

```sh
npm ci
npm run build    # WebAssembly + проверка типов + dist/
```

`dist/` — статические файлы для любого хостинга и любого пути. `.wasm` лучше отдавать с типом `application/wasm`
и сжатием (7 МБ, сжатый — около 2 МБ). Готовый образ с Caddy: `docker build -f deploy/builder.Dockerfile -t tors-builder .`
из корня репозитория.

Маркет берётся из `registry/index.json` при сборке. После изменения модулей обновите индекс:
`go run ./cmd/tors market-index --verified registry/verified -o registry/index.json`.

## Как устроено

| Часть | Где |
|---|---|
| Формат экранов, проверки, шаблоны, отрисовка | `theme/` (Go) → `cmd/ui-wasm` → `public/tors-theme.wasm` |
| Маркет, состав бота, манифест, экспорт `bot.json` | `src/market.ts` |
| Состояние проекта, отмена, автосохранение | `src/store.ts` |
| Холст, панели, симулятор, листы маркета и экспорта | `src/canvas`, `src/inspector`, `src/simulator`, `src/sheets` |
| Вид сообщений Telegram | `src/tg/` — размеры сверены с Telegram Web |
