# Редактор экранов TORS

Веб-редактор темы бота: экраны рисуются на холсте так, как их покажет Telegram, переходы задаются стрелками,
а на выходе получается `theme.json`, который читает бот. Проверки и подстановка переменных — тот же Go-код,
что и в боте (`modules/telegram/theme`), собранный в WebAssembly.

## Что умеет

- **Холст.** Экран — карточка-сообщение Telegram: фото, текст, кнопки в сообщении и клавиатура под ним.
  Точки входа (`/start` для нового и вернувшегося пользователя, другие команды, события) и узлы действий
  с исходами — отдельные узлы.
- **Переходы.** Потяните за точку справа от кнопки к другому экрану. Отпустите в пустом месте — создастся новый экран.
  Выделите стрелку и нажмите Backspace, чтобы убрать переход.
- **Правка.** Нажмите на кнопку или экран — справа откроются свойства:
  - текст по языкам с разметкой и переменными модулей;
  - эмодзи и цвет кнопки (только цвета, которые есть в Telegram);
  - что делает кнопка: экран, действие с исходами, ссылка, Mini App, копирование, назад, в начало;
  - параметры, условия показа, ряды клавиатуры с перетаскиванием, списки, ввод текста.
- **Проверка.** Симулятор-чат: `/start`, нажатия, редактирование сообщения на месте, выбор исхода действия,
  счёт и оплата звёздами, события («оплата прошла», «подписка скоро закончится»), условия, новый/вернувшийся пользователь.
- **Rich / Classic.** Превью в новом формате rich messages и в запасном обычном.
- **Ошибки.** Внизу слева — те же ошибки, что выдаст бот: кнопка никуда не ведёт, нет перевода, нет переменной и т.д.
- **Файлы.** «Файл → Открыть» принимает тему или манифест бота (можно просто перетащить JSON в окно),
  «Экспорт» скачивает или копирует `theme.json`. Положение карточек сохраняется в теме, поэтому экспорт можно снова открыть.
- Автосохранение в браузере, отмена и повтор (⌘Z / ⇧⌘Z).

Всё работает в браузере: редактор ничего никуда не отправляет.

## Запуск

Нужны Go 1.27+ и Node.js 22+.

```sh
npm ci
npm run dev      # собирает WebAssembly и запускает Vite на http://localhost:5173
```

## Сборка для хостинга

```sh
npm ci
npm run build    # WebAssembly + проверка типов + сборка в dist/
```

`dist/` — обычные статические файлы: их можно выложить на любой хостинг (nginx, Caddy, GitHub Pages, S3) в любой путь.

- Файл `.wasm` должен отдаваться с типом `application/wasm`. Если хостинг этого не умеет, редактор всё равно загрузится,
  чуть медленнее.
- Включите gzip или brotli: движок весит 7 МБ, сжатый — около 2 МБ.

## Как устроено

| Часть | Где |
|---|---|
| Формат темы, проверки, шаблоны, отрисовка экрана | `modules/telegram/theme` (Go) |
| Стандартные манифест и тема | `modules/telegram/theme/standard` |
| Мост в WebAssembly | `cmd/ui-wasm` → `public/tors-theme.wasm` |
| Холст, панели, симулятор | `src/` (React, React Flow, Zustand) |
| Вид сообщений Telegram | `src/tg/` — размеры и цвета сверены с Telegram Web |

## Ограничения v0.1

- Вид сообщения — близкое повторение Telegram Web. Приложения Telegram рисуют чуть по-разному,
  точный вид проверяется отправкой экрана в Telegram (появится в боте как `tors ui preview`).
- Как выглядят rich messages в разных клиентах, ещё не сверено: формат новый (Bot API 10.1–10.3).
- Кастомные эмодзи на кнопках показаны заглушкой, фото из локальных файлов (`assets/…`) — заглушкой с именем файла.
- Манифест бота пока берётся стандартный: команда `tors ui manifest` появится вместе с ботом.
